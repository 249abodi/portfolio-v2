# GEO Strategy — Generate Engine Optimization

## Overview

GEO here means structuring content so LLMs and AI search engines can attribute and cite correctly. This is **not** country-targeting — it's entity definition and corroboration.

## The Citation Trinity

Every named entity should appear in **at least 3 pages** with a clear one-line description:

## llms.txt

Generated by `scripts/generate-llms.mjs` from `src/lib/llms-data.json` and written to `public/llms.txt` during `prebuild`.

Format per llmstxt.org:
```
# {Name}
> {One-liner}
## Products
- [Product](URL): description
```

## JSON-LD Schema

Every page carries JSON-LD to define entities:

### Home page (Person)

```json
{
  "@type": "Person",
  "@id": "https://249abodii.vercel.app/#person",
  "name": "Abdulrahman Mohammed" | "عبدالرحمن محمد",
  "jobTitle": "Full-Stack Web Developer",
  "knowsAbout": ["Web Development", "SaaS", "React", ...],
  "sameAs": ["https://github.com/249abodi", ...],
  "alumniOf": { "@type": "CollegeOrUniversity", "name": "Universiti Teknologi Malaysia" }
}
```

### Case study pages (SoftwareApplication + FAQPage)

```json
{ "@type": "SoftwareApplication", "@id": "https://qaveno.vercel.app/#product", "name": "QAVENO", ... }
{ "@type": "FAQPage", "mainEntity": [...] }
```

## GEO ≠ Country Routing

The `/ar/` prefix is a **language/locale** prefix for Arabic-speaking users globally. It is not geo-targeted. SEO hreflang uses `x-default → EN`. There is no IP-based redirect or middleware.

## Key GEO Principles Applied

1. **Entity stability**: Person, QAVENO, ZELVOA each have a stable canonical URL
2. **One-liner consistency**: Same description used in hero, footer, llms.txt, JSON-LD
3. **Co-citation**: Person appears on all pages; product names appear in multiple contexts
4. **Structured data**: JSON-LD on every page type (Person, SoftwareApplication, FAQPage)
5. **Open graph**: Locale-specific og:locale (en_US / ar_SA), canonical + alternates
6. **Schema.org personSameAs**: Only real profiles: GitHub, YouTube, Instagram, Facebook
